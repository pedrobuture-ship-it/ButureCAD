# Gerber viewer (roadmap stage 30)

Tab **Gerber Viewer** (`Ctrl+6`). It draws what the **files** say: the Gerber (RS-274X) and
Excellon bytes are parsed by readers that are independent of the writers (`gerber_read.rs`,
`excellon_read.rs` in `buturecad-manufacturing`) and drawn by a 2D software rasteriser
(`raster2d.rs`: one coverage mask per layer, dark/clear polarity, composited in order). The PCB
model is never drawn here.

## Using it

* *Load current export* generates the manufacturing files (running DRC + preflight) and reads the
  generated bytes back. *Open zip…* reads a stored (uncompressed) `.zip` such as ButureCAD's
  `production.zip`; *Open folder…* reads any folder of `.gtl .gbl .gts … .gko .gbr .drl` files.
* Per-file layer toggles (checkbox), colour by `TF.FileFunction`, *Show all / Hide all*, *Fit*;
  drag pans, the wheel zooms about the cursor.
* Click a layer name: **apertures** (D-code, shape, use count) of a Gerber layer, **tools**
  (diameter, hole count) of a drill layer. Reader warnings are shown per layer.
* **Verification** (live export only): `verify::check` parses the generated files and compares them
  with the board — flash positions, stroke and contour counts, FileFunction, profile extent equal
  to the outline, drill positions and diameters per plating. A mismatch is shown as ✗.

## Supported / not supported

Supported: `FSLA` absolute, mm and inch, `AD` C/R/O/P, `G01/G02/G03`, `G74/G75`, `G36/G37`,
`LPD/LPC`, X2 FileFunction, Excellon metric/inch with decimal coordinates, `G85` slots.
Reported as warnings (never silently ignored): aperture macros (`AM`), step-and-repeat,
mirror/rotate/scale, aperture holes, `G74` centre inference. Errors: trailing-zero omission,
incremental coordinates, undefined apertures, unclosed regions, Excellon without decimal points.
Non-stored ZIP archives are refused. Routed slots (`G00/G01`) in Excellon are not drawn.

## Limits

No measuring, no net highlighting (Gerbers have none), no anti-aliasing, no mirrored bottom view,
no X2 object attributes, no inner-layer negative planes interpretation beyond polarity.
